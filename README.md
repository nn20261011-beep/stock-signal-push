# A股多策略选股信号推送

每交易日 09:00（北京时间）自动扫描全市场，按 13 套经三段验证的策略筛出信号，09:20 前发到邮箱。

- 买入口径统一：T 日收盘出信号 → **T+1 开盘价买入**（剔除开盘一字、ST/退市/除权）
- 每套策略最多 3 只，全信最多 10 只
- 每只标注：适用行情、买入价、卖出规则、历史日等权/胜率/三段、触发依据、题材
- 每天回看历史推送的真实收益（`_push_logs/review.csv`），策略漂移自动预警

策略来自 2016–2026 全市场 184 万样本回测，逻辑分 5 类：
超跌均值回归 / 冰点情绪 / 板块联动 / 趋势低波 / 量能动量。

数据：新浪日线（不复权）、同花顺涨停原因、本地行业分类。
凭证在 GitHub Actions Secrets（SMTP_USER / SMTP_PASS / MAIL_TO）。
