# A股多战法信号推送

跑在 GitHub Actions 上，**不需要本机开机、不需要任何界面挂着**。

## 它做什么

每个交易日北京时间 **09:20** 和 **14:30** 自动运行：
1. 拉全市场主板行情（腾讯行情接口）
2. 按持仓网站 `playbook.js` 的 11 个战法逐个匹配
3. 命中的票写到 `docs/index.html`（GitHub Pages 可直接看）
4. 如果配了邮箱，同时发一封邮件

## 战法来源

全部来自持仓网站 `stock-tracker/playbook.js`，一比一复刻：

| 战法 | 规则 |
|---|---|
| GOLD核心 | MA10>MA20 + 收盘在MA20上方0~3% + 量比1.2~1.5 + 涨幅3~7% |
| 三倍量 | 量比≥2 + 收涨 + 60日分位<40% |
| 369吃货 | 涨幅≥3% + 量比≥1.5 + 收盘位置≥0.8 + 20日振幅≤25% |
| 老鸭头 | MA10>MA20 + 距MA20≤3% + 量比≥1.2 |
| 养家龙头 | 涨停 + 多头排列 + 20日涨幅>15% |
| 科比主流 | 涨幅≥5% + 多头 + 20日>10% + 量比≥1.5 |
| 打板 | 涨幅≥9.5% |
| 炒小炒差 | 距250日高≤-38% + 120日≤-8% + 箱体 + 放量≥1.5 + 长上影 |
| 深V反转 | 布林下轨<0.2 + CCI<-100 + 跌破MA20 + 60日分位<40% |
| 错杀低吸 | 盘中最低跌≤-5% + 收盘跌≤-1% + 从低点反弹≥1% |
| 搓揉线 | 昨长上影 + 今长下影 + 缩量 + 60日分位<40% |

## 怎么配邮箱（可选）

在 GitHub 仓库 Settings → Secrets and variables → Actions 里加：

- `SMTP_USER`：QQ邮箱地址，如 `xxx@qq.com`
- `SMTP_PASS`：QQ邮箱**授权码**（不是登录密码），在 QQ邮箱→设置→账户→POP3/SMTP服务 里生成
- `ALERT_TO`：收件地址

不加也能用，只是不发邮件，改看 GitHub Pages 页面。
